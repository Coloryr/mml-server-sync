# 自选模组

清单里带 `Optional: true` 的条目是自选模组（生成器通常把 `mods/*自选*` 这类文件标成可选）。

## 下载选择制

自选模组按玩家这次的选择决定**是否下载/更新**：

- 勾选：本次下载清单里的版本；本地没有文件时按原名安装；
- 不勾选：本次不下载，本地旧文件（启用或 `.disabled`）原样保留。

勾选不会主动改变文件的启用/禁用状态：本地已有 `xxx.jar` 就更新 `xxx.jar`，
已有 `xxx.jar.disabled` 就更新 `.disabled` 那份，不会因为一次更新把它改回启用。
需要启用/禁用时，直接在游戏目录里改名即可（`.disabled` / 旧版 `.disable` 都认）。
内容仍按 SHA1 / SHA256 比对，哈希一致时直接跳过下载。

选择记录在 `<状态目录>/optional-state.txt`：

```text
内容哈希<TAB>清单路径<TAB>1 或 0
```

- `1` = 上次选择下载/更新，`0` = 上次选择跳过；
- 文件不存在 = 首次同步（交互模式下弹窗并默认全选）；
- 旧版 `skipped.txt` 存在时自动迁移成「跳过」，迁移后删除旧文件；
- 同步成功后原子重写；没有任何记录时删除该文件。

「每次启动都弹窗」的开关记在 `<状态目录>/optional-prompt.txt`（`suppress=1`）：
文件不存在时每次启动都弹，勾了「记住我的选择，以后不再显示」后只在有新增 / 内容变化时弹；
删掉这个文件即可恢复每次弹。

## 弹窗的两个入口

### 自动弹出

- 没有勾「记住我的选择，以后不再显示」时，**每次启动都弹**（包括清单指纹命中、
  包版本未变的启动）；
- 勾过「记住」后只在检测到自选模组**新增 / 内容变化**时弹；
- 新条目在列表里标注「新增」；
- 弹窗打开期间先做不涉及自选模组的清理；**下载计划等玩家确认后才开始**，
  避免没勾的模组已经在后台被下载。确认后按勾选补下这次新勾上的文件，然后写状态、
  放行游戏启动。没勾的旧文件不会在确认前被删除。

### 「自选模组」按钮

进度窗上的常驻按钮，清单解析完成后即可点击，随时打开管理窗修改选择；
下载计划定稿后按钮收起。详见 [ui.md](ui.md)。

## 弹窗内容

表格四列：选择 / 模组 / 介绍 / 状态。

- **介绍**来自发布端手动放在清单地址旁的 `server.json.notes.json`：JSON 对象，
  键是清单里的相对路径，值是简介文字；没有这个文件时留空。这个文件也是更新器的
  可选扩展，MML 不生成。
- **状态**区分新增、需更新、已同步，并附当前本地状态（已启用 / 已禁用）。

关窗、Esc 与「确定」同义：按当前勾选继续，没有取消出口。要中止整次更新，用主窗的
「取消更新」：继续更新 = 恢复同步，跳过本次 = 退出码 0，结束游戏 = 退出码 1。

## 无交互环境

`--no-gui`、headless（无图形环境）、`--no-ask` 下不弹窗：

- 没有记录的条目这次**不下载**；
- 已经记录过的条目按记录执行（`1` 下载，`0` 跳过）。

`--skip` / `--skip-file` 把指定路径按「未勾选」处理（本次不下载，旧文件保留）；
给了 `--skip` 时自动弹窗不再出现，但「自选模组」按钮仍可用。

```text
--skip=mods/a.jar,mods/b.jar      # 可重复
--skip-file skip.txt              # UTF-8，一行一个，# 开头忽略
```

Agent 模式用 `-Dmml.serverSync.skip=...` 或环境变量 `MML_SERVER_SYNC_SKIP`；
默认允许弹窗（Prism 等启动场景窗口前有人），`-Dmml.serverSync.noAsk=true` 或
`MML_SERVER_SYNC_NO_ASK=1` 关掉。

## 已知限制

清单里没有项目编号（`ProjectId`）的条目，身份按路径计算：发布端换了文件名就会被当成
新条目，跳过记录也按路径记，下次会重新询问。
