# 自选模组

清单里带 `Optional: true` 的条目是自选模组（生成器通常把 `mods/*自选*` 这类文件标成可选）。

## 选择制

自选模组的内容**始终参与同步**，勾选只决定装成什么名字：

- 勾选：装成清单里的原名（`xxx.jar`），游戏会加载；
- 不勾选：装成禁用名（`xxx.jar.disabled`，与 MMC / HMCL 的后缀一致），
  玩家可以自己在游戏目录里改名启用，或者下次在弹窗里勾上。

内容更新按 SHA1 / SHA256 比对；只有勾选状态变化时，通常只是改名，不会重新下载。

选择记录在 `<状态目录>/optional-state.txt`：

```text
内容哈希<TAB>清单路径<TAB>1 或 0
```

- 文件不存在 = 首次同步（交互模式下弹窗并默认全选）；
- 旧版 `skipped.txt` 存在时自动迁移成「未勾选」，迁移后删除旧文件；
- 同步成功后原子重写；没有任何记录时删除该文件。

## 弹窗的两个入口

### 自动弹出

- 首次同步（没有选择状态），或检测到自选模组**新增 / 内容变化**时自动弹；
- 新条目在列表里标注「新增」；
- 弹窗**不阻塞同步**：后台继续下载，收尾时暂停，等玩家确认后按勾选把文件归位
  （通常只是改名），然后才写状态、放行游戏启动。

### 「自选模组」按钮

进度窗上的常驻按钮，清单解析完成后即可点击，随时打开管理窗修改选择；
下载计划定稿后按钮收起。详见 [ui.md](ui.md)。

## 弹窗内容

表格四列：选择 / 模组 / 介绍 / 状态。

- **介绍**来自发布端放在清单地址旁的 `server.json.notes.json`：JSON 对象，
  键是清单里的相对路径，值是简介文字；没有这个文件时留空。
- **状态**区分新增、需更新、已同步，并附当前本地状态（已启用 / 已禁用）。

关窗、Esc 与「确定」同义：按当前勾选继续，没有取消出口。要中止整次更新，用主窗的
「取消更新」：继续更新 = 恢复同步，跳过本次 = 退出码 0，结束游戏 = 退出码 1。

## 无交互环境

`--no-gui`、headless（无图形环境）、`--no-ask` 下不弹窗：

- 没有记录的条目按**禁用**安装；
- 已经记录过的条目按记录执行。

`--skip` / `--skip-file` 把指定路径按「未勾选」处理（装成禁用）；给了 `--skip` 时
自动弹窗不再出现，但「自选模组」按钮仍可用。

```text
--skip=mods/a.jar,mods/b.jar      # 可重复
--skip-file skip.txt              # UTF-8，一行一个，# 开头忽略
```

Agent 模式用 `-Dmml.serverSync.skip=...` 或环境变量 `MML_SERVER_SYNC_SKIP`；
默认允许弹窗（Prism 等启动场景窗口前有人），`-Dmml.serverSync.noAsk=true` 或
`MML_SERVER_SYNC_NO_ASK=1` 关掉。

## 已知限制

清单里没有项目编号（`ProjectId`）的条目，身份按路径计算：发布端换了文件名就会被当成
新条目，跳过记录也按路径记，下次会重新询问。
