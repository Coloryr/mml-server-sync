# 进度窗口与界面

同步时默认弹一个 Swing 进度窗（置顶），同步结束就关；Agent 模式同步完立刻关闭，
不拖游戏启动。

进度窗会先尝试创建；安卓启动器（FCL / Zalith / PojavLauncher 等）的 AWT 由 cacio 的
javaagent 提供，而 cacio 排在同步 agent 之后，premain 里初始化 Swing 通常会失败。
失败时记一行「图形界面初始化失败，按无界面同步」，随后不再尝试弹窗、同步照常跑完；
JVM 没有可用图形环境时同样自动退回无界面。

## 窗口内容

- 标题「整合包更新」；确认清单后顶行换成包名与版本。
- 阶段行按流程变化：
  获取清单指纹 → 下载远程配置（细节行显示已接收 MB 数）→ 检查本地文件 → 对比改动 →
  清理旧文件 → 下载文件 (n/N)（细节行显示当前文件名）→ 安装基础文件 → 解压配置包 →
  保存同步状态。
- 细节行（文件名）独占一行，长路径被截断时悬停可看完整名字；
  按钮单独一行靠右，不会被长文件名挤动。

## 按钮

### 取消更新

点下去**立即暂停**同步（下载线程在下一个数据块停住），然后弹出确认框：

- **继续更新**：恢复同步（Esc、关窗、默认按钮都等于继续更新）；
- **跳过更新**：本次不再改动，退出码 0，游戏照常启动；已写入的文件下次启动补齐；
- **结束游戏**：同样不再改动，退出码 1，agent / 启动前脚本据此中止启动。

选择跳过或结束后，进度条立即定格（停在原值、显示「已取消」），窗口最多 2 秒内自行关闭，
不再跟着后台收尾往前走。

### 自选模组

清单解析完成后可点，随时打开管理全部可选模组的弹窗；见
[optional-mods.md](optional-mods.md)。下载计划定稿后按钮收起。

## 关掉窗口

- 命令行 `--no-gui`；
- JVM 属性 `-Dmml.serverSync.gui=false`；
- 环境变量 `MML_SERVER_SYNC_NO_GUI=1`；
- 无图形环境（headless）自动不显示，不用额外参数。

关掉窗口不影响同步与日志，只是没有界面。

## 界面语言

- 按系统语言自动选：`zh*` 用中文，其余一律英文；窗口、帮助、日志都跟着变。
- 强制指定：`-Dmml.serverSync.lang=zh|en` 或环境变量 `MML_SERVER_SYNC_LANG`。
- Prism 等启动器会给游戏 JVM 强制 `-Duser.language=en`；此时按系统编码
  （中文 Windows 为 GBK 系列）与地区码回退识别，界面仍然显示中文。显式覆盖永远优先。
